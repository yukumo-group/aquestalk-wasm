# AqUsrDic wasm32 port

Native wasm32 port of the AqUsrDic 4.1 user-dictionary API.  The module is
freestanding (zero imports) and built from:

* the original AqUsrDic ELF image for the kana table / error messages
  (`src/image.c`, generated by `tools/gen_image.py`);
* a freestanding subset of marisa-trie 0.2.6 (`marisa_fs/`) for the user
  dictionary `TRI1` section;
* `src/api_usr.c` for the CSV / `TOK1` / `MAP1` format and the memory-buffer
  API;
* `src/decomp_check.c` + `src/api_check.c` for `AqUsrDic_Check`.

## Working

```sh
./build_usr32.sh
node test_usr.mjs
```

The test covers:

* `AqUsrDic_Check`: 16/16 against the native `.so`;
* Import of the 17-entry sample CSV, producing a 4636-byte `aq_user.dic`;
* Export of the generated dictionary and of the original
  `aqk2k_lnx/aq_dic/aq_user.dic` (both round-trip the CSV);
* the generated `aq_user.dic` is read correctly by the native AqKanji2Koe
  port (verified with `port/build-native/aqk2k`).

Module: `build-wasm32/aqusr.wasm` (~286 KB, `wasm2wat` reports no imports).

## API

All buffers live in wasm memory; use `aq_alloc`/`aq_free`.

```c
void aus_init(void);
int  aus_set_system_dic(const void *aqdic, unsigned len);
int  aus_import(const char *csv, unsigned csv_len,
                void *out, unsigned out_cap, unsigned *out_len);
int  aus_export(const void *dic, unsigned dic_len,
                char *out, unsigned out_cap, unsigned *out_len);
int  aus_check(const char *surface, const char *yomi, int pos);
const char *aus_error(void);
```

CSV is UTF-8, one `surface,yomi,posCode` record per line, no header.
`aus_set_system_dic` must be called before Import/Export; it parses the
`POSD/POS1` section of the caller-supplied `aqdic.bin`.  The
`aqk2k_lnx/aq_dic/aqdic.bin` sample works.

## Compatibility note

The `TRI1` section is a marisa-trie dictionary.  AqKanji2Koe and this module
read it with ordinary lookup.  AqUsrDic `Export` walks each trie key through
`MAP1` into `TOK1`, and keeps reading the next packed record until bit 7 of
the POS high byte is set.  That bit marks the last reading of the surface.
Import sets it on the last reading of each surface (several CSV rows may
share one surface) and leaves it clear on the readings that precede it.

## Layout

* `marisa_fs/` — vendored marisa-trie 0.2.6 subset, patched for freestanding
  wasm32 (memory-only `Mapper`/`Reader`/`Writer`, tiny C++ std shim in
  `marisa_fs/cxx/`).
* `src/api_usr.c` — CSV parser, kana codec (kana table from the original
  image), `TOK1`/`MAP1`/`TRI1` writer and reader.
* `src/marisa_glue.cc` — C interface to `marisa::Trie`.
* `decomp_usr/all.c` — Ghidra dump used to derive the format and error codes.
