AquesTalk WebAssembly monorepo · 4 engines

Four engines. One demo.

One page for AquesTalk1, AquesTalk2 and AquesTalk10 speech synthesis, plus AqKanji2Koe conversion of kanji/kana mixed text into kana symbols. Every module is x86-64 machine code decompiled to C with Ghidra and rebuilt with clang --target=wasm32 + wasm-ld: no Emscripten, no embind, zero imports.

AquesTalk2

In evaluation builds, na-row and ma-row kana are rendered as ヌ. The generated reading can also be used by the AqKanji2Koe preprocessor in the synthesis tabs.

Modules load on first use.

API: synthe(text, voice) / syntheWithPhont / syntheSjis / syntheUtf16 / convert(text) / convertRoman(text). Errors show the engine name and native error code.

AquesTalk1 / AquesTalk2 / AquesTalk10 / AqKanji2Koe are products of AQUEST Corp. This repository is a research port of the evaluation SDK binaries; using the voice libraries requires a license from AQUEST. The evaluation limits of AquesTalk1/10 and AqKanji2Koe (na-row and ma-row kana → ヌ) are reproduced; AquesTalk2 reproduces the supplied .so's two-byte patch, which distinguishes those kana.
