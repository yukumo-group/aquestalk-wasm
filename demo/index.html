評価版の制限により、ナ行・マ行は「ヌ」と出力されます。生成した読みは 各合成タブの「AqKanji2Koe で変換」と組み合わせても使えます。

API: synthe(text, voice) / syntheWithPhont / syntheSjis / syntheUtf16 / convert(text) / convertRoman(text)。 失敗時はエンジン名とエラーコードを表示します。

AquesTalk1 / AquesTalk2 / AquesTalk10 / AqKanji2Koe は株式会社アクエストの製品です。 このリポジトリは評価用 SDK のバイナリを技術検証のために移植したもので、音声ライブラリの 利用にはアクエスト社のライセンスが必要です。AquesTalk1/10 と AqKanji2Koe の評価版制限 （ナ行・マ行 → ヌ）はそのまま再現し、AquesTalk2 は提供 .so の 2 バイトパッチ （ナ行・マ行を区別）を再現しています。
