AquesTalk2 WebAssembly

規則音声合成エンジン libAquesTalk2Eva.so.2.3 の再コンパイル版。 Ghidra で復元した C を clang で wasm にコンパイルしています（エミュレーションではありません）。

モジュールは最初の合成時に読み込まれます。

API: synthe(text, speed) / syntheWithPhont(text, speed, phontBytes) / syntheSjis / syntheEuc / syntheUtf16 / syntheRoman. 失敗時は null を返し lastError() にエラーコードが入ります。

AquesTalk2 は株式会社アクエストの製品です。このリポジトリは評価用 SDK の バイナリを技術検証のために移植したもので、音声ライブラリの利用には アクエスト社のライセンスが必要です。
